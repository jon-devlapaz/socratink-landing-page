# Diagnostic model

Use this reference for full audits and difficult classifications. The model is a decision aid, not a validated universal equation.

## Contents

1. Unit of analysis
2. Actual-value audit
3. Perception-chain audit
4. Gap taxonomy
5. Binding-constraint decision

## 1. Unit of analysis

Define the value relationship, not merely the artifact:

`subject + audience + job + situation + next-best alternative + time horizon`

The same subject can have different value for different audiences or moments. Do not average incompatible segments into one diagnosis.

## 2. Actual-value audit

Assess these dimensions using direct evidence where possible:

| Dimension | Question | Useful evidence |
|---|---|---|
| Outcome | Does it deliver the job the audience hired it for? | outcome metrics, task completion, customer results |
| Reliability | How consistently does it deliver? | defect, failure, refund, support, or SLA data |
| Quality | Is the result accurate, durable, safe, or well-crafted? | QA, expert review, durability, complaint patterns |
| Time | How quickly does value begin and complete? | onboarding and time-to-value data |
| Effort | What work, learning, and decisions remain for the customer? | usability observation, setup time, service burden |
| Risk | What financial, social, privacy, safety, or opportunity risk remains? | incidents, objections, contract terms, reversibility |
| Accessibility | Who cannot perceive, access, or benefit from it? | accessibility audit, device/language/ability testing |
| Total cost | What does adoption cost beyond sticker price? | switching, integration, training, maintenance |
| Fit | Does it solve this audience’s job better than the alternative? | interviews, switching behavior, competitive tests |

Do not collapse these into one number unless the decision truly requires it.

## 3. Perception-chain audit

| Stage | Failure question | Typical evidence |
|---|---|---|
| Discoverable | Is the relevant value signal noticed? | attention tests, search/findability, first-click behavior |
| Comprehensible | Can the audience explain the value and tradeoffs? | comprehension interviews, recall, task-based tests |
| Credible | Why should this audience believe it will work for them? | comparable proof, methodology, demonstrations |
| Salient | Is the value connected to the current job and alternative? | decision interviews, choice reasons, objection data |
| Experienced | Does every touchpoint reinforce or contradict the promise? | journey observation, support logs, service audits |
| Remembered | What distinction remains later? | delayed recall, referral language, brand associations |

Perception is not merely promotion. Product behavior, service interactions, environments, defaults, packaging, and memory all shape it.

## 4. Gap taxonomy

- **Delivery gap**: the promised outcome is weak, unreliable, slow, effortful, risky, inaccessible, or costly.
- **Fit gap**: the subject may be valuable, but not for this audience, job, moment, or alternative.
- **Evidence gap**: real value exists but lacks credible, comparable, audience-relevant proof.
- **Translation gap**: value exists but is described in features, abstractions, or jargon the audience cannot map to its job.
- **Signal gap**: visible, sensory, social, or structural cues fail to make real quality discoverable.
- **Friction gap**: effort, uncertainty, choice complexity, or access blocks value before it is experienced.
- **Trust contradiction**: a claim, price, interface, policy, or touchpoint conflicts with the promised value.

## 5. Binding-constraint decision

Use this order:

1. Safety, legality, accessibility, and material harm.
2. Delivery and audience fit.
3. Trust contradictions.
4. Evidence and credibility.
5. Comprehension and salience.
6. Signals, distinctiveness, and memory.

Lower items cannot compensate for unresolved higher items. When two gaps remain plausible, say what observation would discriminate between them and recommend measuring before redesigning.

Avoid subjective “value scores” as proof. A score can summarize judgment only when its evidence and uncertainty remain visible.
