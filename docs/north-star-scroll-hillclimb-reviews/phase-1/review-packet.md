## What this is

Phase 1 v1 settles six still compositions under the approved promise (“turning effort into durable
understanding that grows”). Paper-and-ink identity, duet headlines, hairlines, and the one verdigris accent
are carried over. Removed from every frame: tab switchers, steppers, autoplay, the Memory prototype
selector, branded percentages, and seals. Real copy throughout; nothing is a wireframe rectangle. Design
artifact only — not a route, not an app, zero product-source edits.

## The six frames

1. **Hero** — “Study hard material. Turn effort into understanding that grows.” Living ink, single CTA.
2. **How it works** — one authored free response (the carried sampling-bias sentence) with held/gap
   annotations; static step rail. SN2 content deliberately replaced so one thread crosses scenes.
3. **Disciplines** — three specimen dossiers in a settling stack (Statistics marked as the carried thread).
4. **Retention** — qualitative divergence: solid unaided trace vs. evaporating re-read trace; cold answer
   on a *different* problem. No percentages anywhere.
5. **Memory ★ peak** — one composed ledger: verbatim Day-01 words → repair → unaided Day-14 check, haloed bead.
6. **Final** — “Start with one question, leave with understanding that grows.” CTA + ink at rest.

## Signature moment (proposed)

One carried sentence + one ink thread, frames 2 → 4 → 5: authored with annotations (2), re-answered cold
on a different problem (4), preserved verbatim with proof compounding around it (5). The verdigris thread
runs held-underline → unaided trace → terminal bead. Nothing else crosses scenes.

## Reference → design mapping

Apple (one benefit + one scene) → one promise + one focal visual per frame. Linear (restraint, precise
type) → duet headlines and hairlines kept, no new chrome. Pudding (persistent visual changing with scroll)
→ the carried sentence + ink thread. Rams (understandability, restraint) → controls and percentages removed;
reduced-motion states are these same compositions, static.

## Hard gates (still-frame phase; runtime certifiable only in Phase 2+)

Scroll-only comprehension: PASS by design — no frame requires clicking, typing, or waiting. No invented
evidence: PASS — qualitative storytelling + honesty footers (“Illustration only”, “No measured outcome is
claimed”). Readable text: PASS in all 7 stills. Clipping/overlap: none seen. Stuck scroll / reverse states:
not certifiable from stills. Mobile + reduced-motion: phone frame composed; reduced-motion = static frames.

## Taste checks (diagnostic opinions, Jon authoritative)

- Promise clarity 4/5 — hero states growth plainly; the verb returns in frame 6 to close the arc.
- Narrative continuity 4/5 — carried sentence + thread link 2→4→5; frame 3's link (marked thread card) is
  the weakest joint and should be choreographed carefully in Phase 2.
- Composition/material 4/5 — deliberate hierarchy, tonal steps, believable specimens; frame 3's stack is
  slightly airy and can tighten in implementation.
- Motion meaning/pacing N/A — intentions specified per frame; nothing to certify until built.
- Distinctiveness/restraint 4/5 — one focal idea per frame; frames 2/4 excerpt cards rhyme deliberately
  (same voice returning), not by accident.
