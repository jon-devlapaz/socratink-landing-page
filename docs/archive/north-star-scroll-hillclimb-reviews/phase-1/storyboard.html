Six frames: effort becomes understanding that grows

Branch codex/north-star-scroll-hillclimb · approved hero promise: “turning effort into durable understanding that grows” · Identity carried over: paper-and-ink, serif/sans duet, hairlines, one verdigris accent, mono instrument labels. Removed from every frame: tab switchers, stepper controls, autoplay, prototype selectors, branded percentages, seals. Each frame states one promise, one focal visual, one transition intention, and its emotional role. Phone frame (Memory, the hardest scene) closes the set.

Reference → design mapping (concise)

Apple (one benefit + one composed scene) → each frame carries exactly one promise and one focal visual; nothing else competes.
Linear (restraint, precise type) → duet headlines, hairlines, tonal steps kept; no dark SaaS grid, no new chrome.
Pudding (persistent visual changing with scroll) → the carried sentence + ink thread across frames 2→4→5.
Rams (understandability, restraint, longevity) → switchers, steppers, autoplay, and percentages removed; one focal idea per frame; reduced-motion states are the same compositions, static.
